# DSA Problems - Java Implementation

A Java project for solving Data Structures and Algorithms (DSA) problems.

## Project Structure

```
Java/
├── src/
│   ├── main/java/com/dsa/
│   │   ├── arrays/
│   │   ├── strings/
│   │   ├── trees/
│   │   ├── graphs/
│   │   └── linked_lists/
│   └── test/java/com/dsa/
├── pom.xml
└── README.md
```

## Prerequisites

- Java 11 or higher
- Maven 3.6 or higher

## Build

```bash
mvn clean compile
```

## Run Tests

```bash
mvn test
```

## Adding New Problems

1. Create a new package under `src/main/java/com/dsa/` for the topic (e.g., `trees`, `graphs`)
2. Implement your solution class
3. Create corresponding test class under `src/test/java/com/dsa/`
4. Run tests to verify
